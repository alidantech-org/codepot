# OpenAPI adapter task tracking

Read `../design/README.md`, the core source-adapter contract, and `codepotg-v2/docs/00-governance/01-agent-working-rules.md` before claiming work.

- Claim OA task IDs in the central `PARALLEL_WORK.md`.
- Mark `[x]` only after implementation, focused tests, shared source conformance, documentation, and progress evidence pass.
- Record exact test commands/results in `PROGRESS.md`.
- Do not add language, template, pack, writer, CLI, command, or old-generator responsibilities.

The detailed sequence is in [`00-package-plan.md`](00-package-plan.md).
