# Jinja engine task tracking

Read `../design/README.md`, the core template-engine contract, and `dryv/docs/00-governance/01-agent-working-rules.md` before claiming work.

- Claim JINJA task IDs in the central `PARALLEL_WORK.md`.
- Mark `[x]` only after implementation, focused tests, shared engine conformance, adversarial sandbox tests, documentation, and progress evidence pass.
- Record exact test commands/results in `PROGRESS.md`.
- Do not add source, language, pack selection, writer, CLI, command, or old-generator responsibilities.

The detailed sequence is in [`00-package-plan.md`](00-package-plan.md).
