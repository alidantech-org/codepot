# Installation

Install codepot globally or locally in your project.

## Global Install

```bash
npm install -g codepot
```

## Local Install

```bash
npm install --save-dev codepot
```

## Verify Installation

```bash
codepot --version
```

## VS Code Extension

Install the codepot extension for syntax highlighting and autocomplete:

1. Open VS Code
2. Search "codepot Templates" in Extensions
3. Click Install

The extension provides:

- Syntax highlighting for `{| ... |}` templates
- Autocomplete for context variables
- Template validation
