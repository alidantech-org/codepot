# Codepot documentation application

**Status:** Active application boundary

This directory is reserved for the dedicated Codepot documentation application. Canonical authored documentation does not live here; it lives under the repository root [`.docs`](../../.docs/README.md).

The current public documentation renderer is still integrated with [`apps/site`](../site/README.md). Moving that renderer into this application must be completed through an approved task under [`.docs/tasks/apps/docs`](../../.docs/tasks/apps/docs/README.md), without creating a second documentation source.

Do not add Markdown documentation here beyond this README.
