# Skill: maintain documentation

## Use when

Creating, moving, correcting, or publishing repository documentation.

## Procedure

1. Identify the canonical owner under `.docs`.
2. Search for competing or stale copies.
3. Move or merge content without losing evidence.
4. Replace local component docs with concise README links.
5. Update relative links, navigation, publishing manifests, and metadata.
6. Clearly label active, frozen, planned, implemented, and historical content.
7. Validate links and public documentation generation.
8. Confirm `.docs/plan` and `.docs/research` protections when a task excludes them.

## Rule

Never solve drift by creating another copy of the same explanation.
