# Skill: implement task

## Preconditions

The task is ready or assigned, dependencies are complete, ownership is clear, and allowed paths are explicit.

## Procedure

1. Re-read the task and governing architecture.
2. Confirm branch, status, and ownership.
3. Inspect existing code and tests in the allowed paths.
4. Make the smallest coherent change that satisfies the task.
5. Add or update focused tests with the behavior.
6. Run exact validation commands.
7. Review changed paths and diff for scope and architecture violations.
8. Update canonical docs and completion evidence.
9. Move the task to `review`; do not self-declare unsupported completion.
