# Skill: inspect repository

## Use when

Before planning, implementing, auditing, or reviewing repository work.

## Procedure

1. Confirm `develop` and the current head.
2. Read root `AGENTS.md` and component status.
3. Identify the owning active component.
4. Read its local README and canonical docs.
5. Read relevant architecture, tasks, tests, and recent history.
6. Inspect dependency direction and public boundaries.
7. Record contradictions, risks, and unknowns with exact paths.
8. Do not edit during an inspection-only request.

## Output

A grounded summary of current behavior, governing rules, affected paths, unresolved questions, and recommended next action.
