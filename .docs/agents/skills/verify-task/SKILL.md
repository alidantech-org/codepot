# Skill: verify task

## Use when

Reviewing whether an implementation is genuinely complete.

## Procedure

1. Read the task independently of the implementation summary.
2. Compare every acceptance criterion with code and evidence.
3. Run focused, architecture, integration, and manual checks required by the task.
4. Confirm exact commands and results.
5. Inspect forbidden and unrelated paths.
6. Confirm docs, public APIs, packaging, and ownership state where relevant.
7. Record failures and remaining risks precisely.
8. Mark complete only when all required evidence exists; otherwise return to `in_progress`, `blocked`, or `review`.
