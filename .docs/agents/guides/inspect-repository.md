# Inspecting the repository

Begin by proving the current state rather than trusting old task notes or package descriptions.

1. Confirm the repository and `develop` branch.
2. Read root `AGENTS.md` and component status.
3. Locate the relevant app or package.
4. Read its local README and canonical `.docs` pages.
5. Read the assigned task and required architecture.
6. Inspect public APIs, dependency direction, tests, fixtures, and recent relevant history.
7. Identify contradictions between docs, code, and tasks.
8. Report concrete findings before proposing broad changes.

Archived and frozen implementations may be inspected for evidence, but they do not define the active architecture.
