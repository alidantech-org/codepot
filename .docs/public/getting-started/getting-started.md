# Getting started

Dryv is currently an alpha repository project rather than a finished end-user distribution.

## Learn the model

1. Read the [architecture overview](/docs/architecture).
2. Read the [Dryv overview](/docs/dryv).
3. Understand the separation between [authoring](/docs/dryv/authoring), [Runtime IR](/docs/dryv/runtime-ir), [packs](/docs/dryv/packs), and [usage](/docs/dryv/usage).

## Contribute to the repository

1. Work on the existing `develop` branch.
2. Read root `AGENTS.md` when using an AI agent.
3. Confirm the component status before editing.
4. Start only from an approved ready task.
5. Read the governing architecture and product documents under `.docs`.
6. Record exact validation evidence.

## Existing users of earlier packages

The frozen package references remain available under [Packages](/docs/packages). Frozen means retained, not abandoned without notice, but no new feature or architecture work is planned there unless an explicit maintenance task is approved.
