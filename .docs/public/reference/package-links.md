# Package links

External links are centrally configured in `docs/ecosystem.json` and rendered by the site.

Unavailable registry or hosted links remain `null` with `tbd` status. The UI hides them instead of creating broken buttons.

## Reserved future links

The ecosystem configuration already reserves entries for:

- Codepot Lang package or release distribution;
- `codepot` CLI release downloads;
- Codepot LSP binary releases;
- VS Code Marketplace;
- Open VSX;
- Codepot Web source and hosted application;
- Codepot MCP source and package registry.
