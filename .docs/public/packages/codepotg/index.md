# codepotg

> **Status: Frozen.** Retained for existing users and historical comparison. No feature development or architectural redesign is planned.

CodepotG is the earlier Python generator that normalizes OpenAPI and applies Jinja template packs. Its implementation and documentation provided important evidence for Dryv's planning, pack, target-adapter, safety, and performance design.

Existing detailed guides remain available in the repository for maintenance reference.

Use [Dryv](/docs/dryv) for active development.
