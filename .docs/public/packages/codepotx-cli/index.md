# codepotx-cli

> **Status: Frozen.** Retained for historical comparison. No feature development or architectural redesign is planned.

`codepotx-cli` is the earlier thin terminal frontend for `codepotx`.

The active terminal frontend is `dryv-cli`, which presents public Dryv runtime operations without duplicating runtime behavior.

See [Usage and CLI](/docs/dryv/usage).
