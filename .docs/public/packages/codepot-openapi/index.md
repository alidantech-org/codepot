# codepot-openapi

> **Status: Frozen.** Retained for existing users and historical comparison. No feature development or architectural redesign is planned.

`codepot-openapi` is the earlier TypeScript-first authoring and OpenAPI contract package. It helped establish ideas around typed intent, portable contracts, and generator metadata.

Its existing detailed documentation remains in the repository for maintenance reference, but the package does not define the active Codepot architecture.

Use [Dryv authoring](/docs/dryv/authoring) for the current language-neutral direction.
