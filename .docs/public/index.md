# Codepot documentation

Codepot explores whether software intent can be represented in a portable semantic form and then derived into target-specific projects through explicit, deterministic packs.

The active implementation is **Dryv**.

```text
Human or AI intent
    ↓
Dryv authoring source
    ↓
Canonical Dryv Runtime IR
    ↓
Pack selection, binding, planning, and rendering
    ↓
Target source, configuration, documentation, files, and folders
    ↓
Existing compilers, interpreters, frameworks, databases, and runtimes
```

Codepot is not a replacement runtime. It preserves supported software meaning above implementation technologies and uses those technologies rather than recreating them.
