# Codepot project overview

Codepot explores deterministic software derivation from explicit, language-neutral software meaning.

The active implementation family is Dryv. It separates authoring, canonical Runtime IR, templating, and project usage so humans and AI agents can inspect software intent before target-specific source files are produced.

Codepot does not replace programming languages, frameworks, databases, compilers, interpreters, or runtimes. It sits above them and uses reusable packs to derive target-specific artifacts.

The project is alpha research and engineering work. Claims about portability, AI efficiency, reduced review cost, or reduced duplicated testing must be measured rather than assumed. See [`../research/WHY.md`](../research/WHY.md) and [`../research/evidence-and-validation.md`](../research/evidence-and-validation.md).
