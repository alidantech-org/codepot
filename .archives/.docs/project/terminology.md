# Repository terminology

- **Codepot** — the overall project and research thesis.
- **Dryv** — the active deterministic software-derivation product family.
- **Authoring** — a human- and machine-friendly way to define software meaning and compile it into canonical IR.
- **Runtime IR** — the canonical semantic authority owned by the Dryv runtime.
- **Pack** — a reusable definition of how canonical meaning selects templates and becomes target artifacts.
- **Usage** — project configuration that connects authored source or serialized IR, packs, bindings, and destinations.
- **Application** — an executable repository product under `apps/`.
- **Package** — a reusable distributable component under `packages/<ecosystem>/`.
- **Frozen** — retained but not open to ordinary feature or architecture work.
- **Task** — the canonical, reviewable contract for a bounded unit of work.
